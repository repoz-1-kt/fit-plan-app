# FitPlan

Мобильное веб-приложение для расчета питания, алкоголя, воды, тренировок и ведения личного кабинета при похудении.

## Публикация через GitHub Pages

Откройте `Settings -> Pages`, выберите `Deploy from a branch`, ветка `main`, папка `/root`, затем сохраните.

После публикации сайт будет доступен по адресу:

https://repoz-1-kt.github.io/fit-plan-app/
